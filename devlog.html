Behind the scenes

Dev log

A running record of how LabRelay got built — what changed, and why.

v1.4

Plain redesign + dev log

Simplified the whole look — flatter buttons, no decorative hero cards, a plain nav. Added this dev log page.

v1.3

Submission flow

Once a researcher accepts a student, the student now sees the researcher's contact email and can submit a link to their finished work, which the researcher can view from My Tasks.

v1.2

Applications

Students can now apply to a task with a short note. Researchers review applicants on a new "My Tasks" page and accept or decline. Students track their own status on "My Applications."

v1.1

Accounts

Added real login and sign-up with Firebase — email/password and Google. Every posted task and application is now tied to a real account instead of being anonymous.

v1.0

First live version

Launched the first working version of the task board — post a task, browse tasks — backed by a real database instead of a static page.
