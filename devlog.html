Behind the scenes

Dev log

A running record of how LabRelay got built — what changed, and why.

August 15, 2026

First real outreach and first real student

Sent outreach to 6 researchers, got my first real student signup, aiming for first live task by January 1st, 2027.

August 9, 2026

Task management for researchers

Researchers can now mark a task as filled once someone's accepted, edit a task's details, or delete one entirely. Filled tasks no longer clutter the public board.

August 8, 2026

Registered for the Congressional App Challenge

Started the official submission for Maryland's 6th District.

August 8, 2026

Sent the first outreach emails

Reached out to real researchers at the University of Maryland with the live link, asking if they'd be willing to post a task.

August 3, 2026

Decided to start LabRelay

Landed on the idea: a task board connecting researchers who need help with small tasks to students who want real experience.

August 3, 2026

Vibe-coded the first version with Claude

Built the first working prototype — the landing page, the task board, and the posting form.

August 3, 2026

Got a GitHub repo

Set up a GitHub repo and got the site live for the first time.
